**EduQuest SMA** adalah aplikasi web game edukasi interaktif yang dirancang khusus untuk siswa SMA (Sekolah Menengah Atas). Aplikasi ini menggabungkan konsep *gamification* untuk membuat proses belajar mata pelajaran Matematika, Fisika, Kimia, Biologi, dan Sejarah menjadi menyenangkan dan mengasah otak.

---

## 🌟 Fitur Utama

- 📚 **5 Mata Pelajaran SMA**: Matematika, Fisika, Kimia, Biologi, & Sejarah.
- ⚡ **2 Mode Permainan**:
  - **Kuis Kilat**: Pilihan ganda dengan countdown timer, streak multiplier (combo), dan pembahasan ringkas.
  - **Teka-Teki Pasangan (Matching Game)**: Menjodohkan istilah dengan definisi secara visual & interaktif.
- 🔊 **Web Audio API Synthesizer**: Efek suara dinamis (*correct*, *wrong*, *win*) tanpa memerlukan file audio eksternal.
- 🌙 **Dark & Light Theme**: Mendukung mode terang dan gelap yang dapat disesuaikan.
- 📊 **Metrik & Peringkat**: Penghitungan akurasi skor, combo multiplier, serta animasi selebrasi *confetti*.
- 📱 **Fully Responsive**: Nyaman dimainkan dari perangkat smartphone, tablet, maupun komputer.

## 🛠️ Cara Deploy ke GitHub Pages

Kamu dapat mempublikasikan game ini secara gratis melalui **GitHub Pages**:

1. Buat repository baru di GitHub (misal: `eduquest-sma`).
2. Upload file `index.html`, `style.css`, `script.js`, dan `README.md` ke repository tersebut.
3. Buka tab **Settings** di repository GitHub milikmu.
4. Pilih menu **Pages** di panel sebelah kiri.
5. Pada bagian **Build and deployment -> Source**, pilih `Deploy from a branch`.
6. Pilih branch `main` (atau `master`) dan folder `/root`, lalu klik **Save**.
7. Tunggu beberapa saat, web game kamu akan online di URL `https://username.github.io/eduquest-sma/`!
